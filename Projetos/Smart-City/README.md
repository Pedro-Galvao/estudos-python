# Smart City — Cidade Inteligente

Projeto de redes desenvolvido no Cisco Packet Tracer para representar uma cidade inteligente (Smart City), com ambientes conectados e serviços de rede.

## Arquivos originais

Os arquivos originais do projeto são:
- `Cidade Redes.pkt` — topologia do Cisco Packet Tracer.
- `Integrantes e funções.docx` — documento com a divisão de responsabilidades da equipe.

**Importante:** esta pasta contém a documentação em Markdown. Os arquivos binários originais ainda precisam ser enviados para o GitHub para que a topologia possa ser aberta diretamente daqui.

## Como utilizar

1. Abra o Cisco Packet Tracer.
2. Abra o arquivo `Cidade Redes.pkt`.
3. Consulte a divisão de tarefas da equipe no documento de integrantes.
