# Projeto de Redes — Cidade IoT

Projeto acadêmico desenvolvido com Cisco Packet Tracer, envolvendo a estrutura de uma cidade conectada (Cidade IoT) e diferentes ambientes de rede.

## Arquivos do projeto

- `Cidade Redes.pkt` — arquivo de topologia para abrir no Cisco Packet Tracer.
- `Integrantes e funções.docx` — documento original com a divisão de responsabilidades da equipe.

> Observação: os arquivos binários originais (`.pkt` e `.docx`) ainda precisam ser enviados para esta pasta pelo site do GitHub. Esta documentação foi publicada para preparar a organização do projeto.

## Como abrir

1. Instale e abra o Cisco Packet Tracer.
2. Abra o arquivo `Cidade Redes.pkt`.
3. Consulte a divisão de tarefas em `Integrantes e funções.docx`.

## Objetivo

Documentar e organizar o projeto de redes da cidade conectada, reunindo a topologia e as responsabilidades da equipe em um único local.
