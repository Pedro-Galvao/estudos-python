# Jogo da Velha — Python

Projeto de jogo da velha com interface gráfica desenvolvido em Python usando Tkinter.

## Como executar

1. Extraia `Projeto Python.zip`.
2. Abra a pasta extraída no VS Code.
3. Execute `main.py` com Python 3 instalado:

```bash
python main.py
```

O Tkinter normalmente acompanha a instalação padrão do Python para Windows. O projeto usa a fonte Ivy na interface; caso ela não esteja disponível no sistema, a aparência da fonte poderá variar.
