# Estudos de Python

Repositório de exercícios e pequenos programas desenvolvidos durante os estudos iniciais de Python.

Os arquivos estão organizados por assunto: atividades, condicionais, listas, entrada e saída, laços de repetição e desafios práticos.

## Como executar

1. Instale Python 3.
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do arquivo desejado.
4. Execute `python nome_do_arquivo.py` (no Windows, também pode usar `py nome_do_arquivo.py`).

Estes são exercícios de aprendizagem; alguns podem estar incompletos ou conter erros próprios da etapa de estudo e não devem ser tratados como aplicações de produção.
